# 编译运行 linux-0.01
{docsify-updated}

> https://github.com/mariuz/linux-0.01

## 编译
```
sudo apt-get install -y bin86 gcc build-essential gcc-multilib qemu-system-x86
make
```

## 直接运行编译好的内核
macos 上直接运行：
1. 安装 qemu : `brew install qemu`
2. 在项目目录下运行 `dd if=/dev/zero of=Image bs=1 count=0 seek=1474560` 将 Image 补足到 1.44MB
3. 修改 makefile 的 run 命令为: `qemu-system-i386 -drive format=raw,file=Image,index=0,if=floppy -boot a -hdb hd_oldlinux.img -m 8 -machine pc`
4. `make run` 运行


## 调试

### QEMU + GDB（最适合调进入保护模式后的 C 内核）
`Makefile`  的  `CFLAGS`  带了  `-g` ，链接用  `-Ttext 0 -e startup_32`  并生成了  `System.map` ； `tools/system`  是带符号的 ELF（ Image  是去符号的裸二进制）。所以 GDB 要加载符号就用  `tools/system` 。
1. 启动 QEMU 并等待 GDB（在  make run  命令基础上加  -s -S ）：
```
qemu-system-i386 -drive format=raw,file=Image,index=0,if=floppy -boot a -hdb hd_oldlinux.img -m 8 -machine pc -S -s -d in_asm,cpu,int -monitor stdio
```
+ `-s`: 开  `1234`  gdb 端口， 
+ `-S`:  启动即暂停等你连。
+ `-d in_asm,cpu,int` ：把执行的指令、CPU 状态、中断打日志到终端。
+ `-monitor stdio`: 启动 QEMU monitor

2. 另起终端  `gdb tools/system`  连上 QEMU：
```
gdb
(gdb) target remote host.docker.internal:1234
(gdb) symbol-file tools/system      # 加载内核符号（地址基于 -Ttext 0）
(gdb) break startup_32              # head.s 里保护模式入口
(gdb) break main                    # init/main.c 的 main()
(gdb) break sched_init
(gdb) continue
(gdb) info registers
(gdb) bt
(gdb) x/20i $pc
```

一开始 CPU 处于 16 位实模式，GDB 对实模式支持有限；调引导阶段建议用 Bochs，等跳到  `startup_32/main`  之后用 GDB 调 C 代码最顺。可以先  `break *0x7c00`  手动跟引导，也可以直接  `break startup_32`  跳过引导。

3. QEMU monitor
```
info registers # 查看寄存器,包括gdtr/idtr 等gdb 中不显示的寄存器
```

### 方案一：Bochs 内置调试器（最适合调 boot.s 这种实模式代码）
仓库里的  `bochsrc.txt`  已经为调试配置好了：
```
bochs -f bochsrc.txt  
bochs -f bochsrc.txt -debugger
```

调试命令：
```
b 0x7c00      # 在引导入口下断点
c             # 继续运行，命中后停下
u /20         # 反汇编接下来 20 条指令
sreg          # 看 cs/ds/es/ss 等段寄存器
r             # 看通用寄存器
xp /16bx 0x7c00   # 查看物理内存
s             # 单步
```

调实模式（段:偏移、 mov ds,ax  之类）时 Bochs 比 GDB 直观得多，还能看段寄存器、物理内存，推荐调引导阶段用它。

也可以用「魔术断点」：把  bochsrc.txt  里改成  magic_break: enabled=1 ，然后在你想停的汇编处插一条  xchg bx,bx ，运行到那里就会自动断下。
