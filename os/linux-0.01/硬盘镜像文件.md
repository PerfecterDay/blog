## 硬盘镜像文件格式
```
LBA 0
512 字节

MBR
偏移 0–445：引导代码及相关数据（446 字节）
偏移 446–509：4 个分区表项（64 字节）
偏移 510–511：结束标志 55 AA


LBA 1、LBA 2……
后续扇区，可以存放分区、文件系统、文件或其他数据。
```

分区表项的结构：
| 字节偏移量 | 长度 | 字段名称 | 说明 |
| :--- | :--- | :--- | :--- |
| **00H** | 1 字节 | **引导标志（Status / Active）** | `80H` 表示活动分区（可引导），`00H` 表示非活动分区。 |
| **01H - 03H** | 3 字节 | **起始磁头、柱面、扇区（CHS）** | 分区起始的磁头号、柱面号和扇区号（旧寻址方式）。 |
| **04H** | 1 字节 | **分区类型（Type）** | 标识文件系统类型（如 `07H` 为 NTFS，`0BH` / `0CH` 为 FAT32，`83H` 为 Linux 等）。 |
| **05H - 07H** | 3 字节 | **结束磁头、柱面、扇区（CHS）** | 分区结束的磁头、柱面和扇区号。 |
| **08H - 0BH** | 4 字节 | **起始扇区（LBA）** | 采用逻辑块地址表示的分区起始扇区绝对编号（32位整数）。 |
| **0CH - 0FH** | 4 字节 | **总扇区数（Size）** | 该分区包含的扇区总数（32位整数，限制了单分区最大约为 2TB）。 |

## 创建硬盘镜像文件
```
dd if=/dev/zero of=disk.img bs=512 count=20480

xxd -g 1 -l 512 disk.img //xxd 查看镜像前 512 字节

# 分区表：偏移 446，长度 64 字节
xxd -g 1 -s 446 -l 64 disk.img

# MBR 结束标志：偏移 510，长度 2 字节
xxd -g 1 -s 510 -l 2 disk.img
```

## linux
`init/main.c` 的 `init()` 方法:
```
void init(void)
{
	int i,j;

	setup();
	(void) open("/dev/tty0",O_RDWR,0);
	(void) dup(0);
	(void) dup(0);
	printf("%d buffers = %d bytes buffer space\n\r",NR_BUFFERS,
		NR_BUFFERS*BLOCK_SIZE);
	printf(" Hello from my kernel.\n\r");
	if ((i=fork())<0)
		printf("Fork failed in init\r\n");
	else if (!i) {
		close(0);close(1);close(2);
		setsid();
		(void) open("/dev/tty0",O_RDWR,0);
		(void) dup(0);
		(void) dup(0);
		_exit(execve("/bin/sh",argv,envp));
	}
	j=wait(&i);
	printf("child %d died with code %04x\n",j,i);
	sync();
	_exit(0);	/* NOTE! _exit, not exit() */
}
```

`setup()` 会执行 `sys_setup`(在`kernel/hd.c`中) 系统调用：
```
int sys_setup(void)
{
	static int callable = 1;
	int i,drive;
	struct partition *p;

	if (!callable)
		return -1;
	callable = 0;
	for (drive=0 ; drive<NR_HD ; drive++) {
		rw_abs_hd(READ,drive,1,0,0,(struct buffer_head *) start_buffer);
		if (!start_buffer->b_uptodate) {
			printk("Unable to read partition table of drive %d\n\r",
				drive);
			panic("");
		}
		if (start_buffer->b_data[510] != 0x55 || (unsigned char)
		    start_buffer->b_data[511] != 0xAA) {
			printk("Bad partition table on drive %d\n\r",drive);
			panic("");
		}
		p = 0x1BE + (void *)start_buffer->b_data; //0x1BE 是分区表的起始偏移量
		for (i=1;i<5;i++,p++) {
			hd[i+5*drive].start_sect = p->start_sect;
			hd[i+5*drive].nr_sects = p->nr_sects;
		}
	}
	printk("Partition table%s ok.\n\r",(NR_HD>1)?"s":"");
	mount_root();
	return (0);
}
```
