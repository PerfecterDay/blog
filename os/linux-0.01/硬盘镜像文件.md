# 硬盘镜像文件
{docsify-updated}

## 格式
```
LBA 0
512 字节

MBR
偏移 0–445：引导代码及相关数据（446 字节）
偏移 446–509：4 个分区表项（64 字节）
偏移 510–511：结束标志 55 AA


LBA 1、LBA 2……
后续扇区，可以存放分区、文件系统、文件或其他数据。
```

## 创建硬盘镜像文件
```
dd if=/dev/zero of=disk.img bs=512 count=20480

xxd -g 1 -l 512 disk.img //xxd 查看镜像前 512 字节

# 分区表：偏移 446，长度 64 字节
xxd -g 1 -s 446 -l 64 disk.img

# MBR 结束标志：偏移 510，长度 2 字节
xxd -g 1 -s 510 -l 2 disk.img
```
