# C 语言 ABI
{docsify-updated}

System V AMD64 ABI
第1个 → RDI
第2个 → RSI
第3个 → RDX
第4个 → RCX
第5个 → R8
第6个 → R9

C ABI 仍然会使用栈传递参数，只是在 Linux x86-64 常用的 System V AMD64 ABI 中，前 6 个整数或指针参数优先通过寄存器传递。前六个参数从寄存器中获取，后续参数则从调用者准备的栈参数区域读取。

C ABI 并没有规定所有参数都必须通过寄存器传递，具体取决于平台 ABI、参数类型和参数数量。

使用寄存器主要是为了提高调用效率：
- 减少参数入栈、出栈的内存操作。
- 降低函数调用的开销。
- 利用 CPU 寄存器直接传递常用参数。
不过，栈仍然非常重要。它还用于保存返回地址、存储部分局部变量、保存寄存器以及传递超出寄存器容量的参数等。


## cdel
标准 cdecl 调用约定下的栈帧示意图:
```
高地址 (主调函数的领地)
  |   ... 主调函数的局部变量 ...
  |   参数 2
  |   参数 1                 <-- [EBP + 8] (被调函数访问参数的起点)
  |   返回地址 (Return Addr) <-- [EBP + 4] (CALL 指令自动压入)
---------------------------------------- 两个栈帧的分界线
  |   旧的 EBP               <-- 【当前 EBP 指向这里】
  |   局部变量 1             <-- [EBP - 4]
  |   局部变量 2             
低地址 (被调函数的领地)       <-- 【ESP 指向当前栈顶】
