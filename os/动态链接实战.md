# 动态链接实战
{docsify-updated}

## 代码
```
// add.c
int add(int a, int b){
    return a + b;
}
```

```
// sub.c
int sub(int a, int b) {
    return a - b;
}
```

```
// pie,c
#include <stdio.h>

extern int add(int,int);
extern int sub(int,int);

int main(int argc, char *argv[]) {
    printf("%d\r\n",add(1,2)) ;
    printf("%d\r\n",sub(1,2)) ;
    return 0;
}
```

## 编译
```
musl-gcc -fPIC -shared add.c -o add.so
musl-gcc -fPIC -shared sub.c -o sub.so
musl-gcc -o pie pie.c add.so sub.so
```
