sing-box 使用 JSON 作为配置文件格式。
```
{
  "log": {},
  "dns": {},
  "ntp": {},
  "certificate": {},
  "certificate_providers": [],
  "endpoints": [],
  "inbounds": [],
  "outbounds": [],
  "route": {},
  "services": [],
  "experimental": {}
}
```
## log
在 config.json 文件中，log 字段用于指定 Sing-Box 服务器的日志记录选项。这包括应执行的日志记录级别以及日志文件的保存位置。
```
"log": {
	"disabled": false,
	"level": "error",
	"output": "box.log",
	"timestamp": true
}

trace
debug
info
warn
error
fatal
panic
```

## DNS
DNS 也是 Singbox 配置中的可选部分。对于位于 DNS 审查环境下的 Singbox 客户端而言，这可能非常有用。可以将 Singbox 配置为使用特定的 DNS 服务器或一组 DNS 服务器来解析域名。还可以为 Singbox 创建规则，以确定如何使用每台服务器。
```
"dns": {
	"servers": [],
	"rules": [],
	"final": "",
	"strategy": "",
	"disable_cache": false,
	"disable_expire": false
}
```

Sing-Box 允许您从多种 DNS 协议中进行选择，并配置用于域名查询的服务器。可以创建规则，指定某些域名应通过不同的 DNS 服务器进行查询。
当您希望避免被视为试图绕过审查时，此功能非常有用，因为缺乏 DNS 流量可能会引起怀疑。
针对特定域名使用您的 ISP 的 DNS，将使您的在线活动在外部观察者看来更符合常规。
例如，以下配置使用 dci.ir 的 DNS 服务器查询所有 .ir 域名，其余域名则发送至 Google 的 8.8.8.8 服务器。
```
"dns": {
	"servers": [{
			"tag": "local",
			"address": "217.218.127.127",
			"detour": "direct"
		},
		{
			"tag": "google",
			"address": "tls://8.8.8.8"
		}, {
			"tag": "block",
			"address": "rcode://success"
		}
	],
	"rules": [{
		"geosite": "category-ads-all",
		"server": "block"
	}, {
		"domain_suffix": "ir",
		"server": "local"
	}],
	"final": "google",
	"strategy": "prefer_ipv4",
	"disable_cache": false,
	"disable_expire": false
}
```
在上例中，“绕行”指的是 DNS 流量将被发送至何处。如果未定义绕行路径，特定的 DNS 服务器流量将通过您的默认出站路径发送，该路径将在后续的路由部分中定义。

若要利用 Sing-Box 拦截客户端的 DNS 流量，必须启用特定入站接口的嗅探功能。此外，您也可以通过路由部分中的“dns-out”选项来路由 DNS 流量。以下是官方文档中的一个示例。

## Inbounds
入站控制的是 sing-box 作为一个服务器，给那些需要走 sing-box 代理提供的协议支持以及其他控制。控制入站的流量

+ `direct` 入站是一个隧道服务器。
+ `mixed` 入站是一个 socks4, socks4a, socks5 和 http 服务器.
+ `socks` 入站是一个 socks4, socks4a 和 socks5 服务器.
+ `http` 入站是一个 http 服务器.
+ `shadowsocks`
+ `vmess`
+ `trojan`
+ `naive`
+ `hysteria`
+ `shadowtls`
+ `vless`
+ `tuic`
+ `hysteria2`
+ `anytls`
+ `tun`
+ `redirect`
+ `tproxy`
+ `cloudflared` : cloudflared 入站运行一个内嵌的 Cloudflare Tunnel 客户端，并将所有传入的隧道流量 （TCP、UDP、ICMP）通过 sing-box 的路由引擎转发。


```
{
  "type": "tun",
  "address": ["172.19.0.1/30"],
  "auto_route": true,
  "strict_route": true
}
```

TUN --> https://www.baeldung.com/linux/tun-interface-purpose

## Outbounds
出站控制的是 sing-box 作为一个客户端，连接到远端服务器（VPS、订阅的服务器）的协议以及其他控制。控制出站的流量。

## 命令
```
sing-box check // 检查配置文件是否有问题
sing-box format -w -c config.json -D config_directory //格式化
sing-box merge output.json -c config.json -D config_directory //合并
```
