# 配置
{docsify-updated}

> https://sing-box.sagernet.org/zh/configuration/

sing-box 使用 JSON 作为配置文件格式。
```
{
  "log": {},
  "dns": {},
  "ntp": {},
  "certificate": {},
  "certificate_providers": [],
  "endpoints": [],
  "inbounds": [],
  "outbounds": [],
  "route": {},
  "services": [],
  "experimental": {}
}
```

```
sing-box check // 检查配置文件是否有问题
sing-box format -w -c config.json -D config_directory //格式化
sing-box merge output.json -c config.json -D config_directory //合并
```
