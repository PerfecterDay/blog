# 搭建 go 开发环境
{docsify-updated}

## linux 安装 go
1. 下载安装包：https://go.dev/dl/
2. `rm -rf /usr/local/go && tar -C /usr/local -xzf go1.26.5.linux-amd64.tar.gz`
3. 配置环境变量：`vim ~/.profile`，添加如下内容：
    ```
    export PATH=$PATH:/usr/local/go/bin
    export PATH="$PATH:$(go env GOPATH)/bin"
    ```
4. 验证: `source  ~/.profile`  然后执行  `go version`
